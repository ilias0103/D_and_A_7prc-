Контрольные вопросы

7. Что такое JavaScript?
JavaScript — язык программирования, который используется для создания интерактивности на веб-страницах.

8. Чем отличается JS от HTML и CSS?
HTML отвечает за структуру страницы, CSS — за оформление, JavaScript — за поведение и интерактивность.

9. Как подключить JS к HTML?
Можно написать JavaScript внутри тега script или подключить внешний файл через <script src="script.js"></script>.

10. Что такое переменная?
Переменная — это именованное место для хранения значения.

11. Разница между let и const?
let позволяет изменять значение переменной, а const используется для значения, которое нельзя переназначить.

12. Что такое функция?
Функция — это блок кода, который выполняет определенное действие и может вызываться по имени.

13. Что такое событие?
Событие — действие пользователя или браузера, например нажатие кнопки, ввод текста или наведение мыши.

14. Как работает addEventListener?
addEventListener добавляет обработчик события для выбранного элемента.

15. Что такое DOM?
DOM — объектная модель документа, через которую JavaScript может обращаться к элементам HTML и изменять их.

16. Как изменить текст элемента через JS?
Например: element.textContent = "Новый текст";
